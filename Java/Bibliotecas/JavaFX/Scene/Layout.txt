// StackPane:
import javafx.scene.layout.GridPane;

StackPane layout = new StackPane(); // Cria um layout para scene
layout.getChildren().add(node); // Adiciona algo ao layout

-------------------------------------------------------------------

// GridPane:
import javafx.scene.layout.GridPane;

GridPane grid = new GridPane(); // Cria um layout GridPane
grid.setAlignment(Pos.CENTER); // Define o Alinhamento do GridPane
grid.setHgap(10); // Define o vão horizontal entre as colunas
grid.setVgap(10); // Define o vão vertical entre as colunas
grid.setPadding(new Insets(25, 25, 25, 25)); // Define a distância entre os lados do layout (top, right, bottom, left)
grid.add(node, 0, 0, 1, 1); // Adiciona algo à grid (node, row, column, rowSpan, columnSpan)

-------------------------------------------------------------------

Layouts são containers que guardam nodes para melhor organização.
