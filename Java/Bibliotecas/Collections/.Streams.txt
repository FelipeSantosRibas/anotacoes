Exemplo de comando com Stream:

List.stream().filter(i -> i.startsWith("A")).collect(Collectors.toList());

--------------------------------------------------

filter() // filtra todos os valores de uma collection
map() // executa uma ação em todos os valores de uma collection
flatMap() // transforma cada elemento em vários elementos e torna tudo uma única stream
reduce() // combina todos os valores de uma collection em um único resultado
collect(Collectors.toList()) // transforma de volta em uma collection
toList// transforma de volta em uma lista
sorted() // ordena todos os valores de uma collection (use Comparator)
max() min() 
findFirst() // pega a primeira ocorrência de um filtro (retorna um Optional<>)
findAny() // findFirst para buscar em outra thread (junto como .parallelStream())

peek() // permite processar os dados para debuggar
