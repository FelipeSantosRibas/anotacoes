Creating a new Thread:

public class RunnableClass implements Runnable{
	@Override
	public void run(){}
}

----------------------------------------------------

Instantiating new Thread:

Thread thread = new Thread(new RunnableClass());

----------------------------------------------------

Methods:

thread.start(); // Start running new thread
thread.join(); // Wait till thread ends

Thread.sleep(1000); // Wait one second on the current thread


System.exit(0)
