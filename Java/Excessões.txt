TRATAMENTO DE EXCESSÕES:
-----------------------------------------------

TRY-CATCH (tente):

try {
  <instrução>; // Tente
}
catch(Exception e) { // Exception pode ser substituído por excessão expecífica
  <instrução>; // Caso corra um erro
} finally {
  <instrução>; // Depois de tudo
}

-----------------------------------------------

Excessões customizadas:

public class CustomException extends Exception{
	public CustomException (String message) {
        	super(message);
    }
} // Cria uma exceção customizada

throws Exception // Indica qual exceção será lançada caso ocorra um erro

throw new Exception(""); // lança uma exceção
