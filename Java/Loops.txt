WHILE (Enquanto):

while( <condição> ){
	<instrução>;
}

----------------------------------------------------------

DO WHILE (Faça enquanto) (executa pelo menos uma vez):

do {
	<instrução>;
}while( <condição> );

----------------------------------------------------------

FOR (para):

for( <inicialização>; <condição>; <interação> ){
	<instrução>;
}

----------------------------------------------------------

FOR EACH (para cada):

for(<tipo> <variável>: <array>){
	<instrução>;
}

----------------------------------------------------------

* Palavras chaves:

break: Sai do loop.
continue: Volta pro começo do loop.
