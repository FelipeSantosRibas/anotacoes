Básicos:

Escreva uma String assim: "isso é uma string".
Você pode juntar uma string com outra, váriáves, operações, métodos assim: "isso é uma "+"String"+25-2*x
Você pode fazer uma String em formado de lista assim:
"""
item 1
item 2
item 3
"""

Métodos úteis:

// Transforma a String
string.substring(int beginIndex, int endIndex): Retorna uma substring a partir de beginIndex até endIndex. Também funciona sem o endIndex.
string.toUpperCase(): Transforma a string em letras maiúsculas.
string.toLowerCase(): Transforma a string em letras minúsculas.
string.trim(): remove os espaços da string.
string.split(String regex): separa a string em todas as substrings regex e retorna em um array de string.
string.replace('a','b'): troca todas as ocorrências de a por b.
string.replaceAll("a","b"): troca todas as substrings iguais a por b.
string.replaceFirst("a","b"): troca a primeira substring igual a por b.

// Verifica a String
string.length(): Retorna o tamanho da string
string.isEmpty(): Retorna true se a string está vazia.
string.isBlank(): Retorna true se a string está vazia ou contém apenas espaços.
string.compareTo(string2): Compara a ordem lexicográfica de duas strings, retorna um valor inteiro.
string.equals(s2): Compara se duas strings são iguais, retorna um valor booleano.
string.equalsIgnoreCase(s2): Compara se duas strings são iguais ignorando maiúsculas, retorna um valor booleano.
string.contains(""): retorna true se a string contém ""
opcao.matches(regex): verifica se a string condiz sum uma expressão regular.
string.endsWith(String regex): Retorna true se a string termina com a substring regex;
string.startsWith(String regex): Retorna true se a string começa com a substring regex;
string.startsWith(String regex, int offSet): Retorna true se a string a partir de offSet começa com a substring regex;
string.indexOf(): Retorna o índice da primeira ocorrência de "" ou char <c> na string1.
string.charAt(int index): Retorna o caractere da string1 no índice especificado.
string.lastIndexOf(): Retorna a posição da última ocorrência da string ou char na string especificada.
